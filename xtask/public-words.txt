# The words of the maintainers' private working setup, which public text
# does not use (`cargo xtask rules`, "Public text" in docs/testing-and-ci.md).
#
# The list was taken from what pull request #106, the public docs pass,
# took out of the docs. A word belongs here when it names the maintainers'
# own machines, scripts or way of running sessions, not the product.
#
# Lines, one entry each; a line that starts with `#` is a comment:
#
#   word PHRASE => ALTERNATIVE    a phrase public text does not use, in any
#                                 case, and what to say instead
#   cased PHRASE => ALTERNATIVE   the same, in exactly this case (the
#                                 product's Coordinator is spelt with a
#                                 capital and is not the maintainers)
#   exact PHRASE => ALTERNATIVE   in any case, with no plural taken: for a
#                                 phrase whose plural is a verb
#   allow PHRASE -- REASON        a longer phrase that is the product's own
#                                 use of a word: a hit inside it passes.
#                                 Never in AGENTS.md.
#   history FOLDER -- REASON      a folder of step records written before the
#                                 rule; its records keep their words
#
# A phrase that begins or ends with a letter or digit matches only as a
# whole word there: `the desk` is not found in `the desktop`; an `s` after
# it is taken (`laptops`), except for an `exact` phrase. A phrase is found across a line break and across
# runs of spaces, within a paragraph.
