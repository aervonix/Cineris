Write the release notes for version {{version}} of this project, for {{audience}}.

Take them from the changelog's entry for {{version}} (`CHANGELOG.md`, or wherever this project records its changes), and add nothing the entry does not say. Put first what a reader must do: a change that breaks something, and how to adapt to it. Then what they gain, then what was fixed. Leave out changes that matter only to the people who work on the project. One sentence a change.

Show me the notes. Do not write them to a file until I ask.
