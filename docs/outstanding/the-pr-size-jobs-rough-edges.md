None lets a home path into a binary or delays a required check. **(1) The tools that read a whole `ci` run now see `pr-size` too:** the owner's `ci-wait --pr N` waits for it, about four minutes more, and reads a red `pr-size` (a binary over its budget) as a failed run; `cargo xtask ci-times` puts `pr-size-linux` and `pr-size-windows` in a step's job table beside the 5-minute jobs.
