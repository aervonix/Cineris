| **Whether Notepad, the default external editor on Windows, waits.** `Ctrl+G` with neither `VISUAL` nor `EDITOR` set runs `%SystemRoot%\System32\notepad.exe` and waits for it to end. The tabbed Notepad of Windows 11 may hand the file to a window already open and end at once (step 21's review; not confirmed, since no Windows 11 desktop is reachable from CI). The prompt is then read back unchanged and kept as it was, but its folder is removed while the user may still be editing, so a later save is lost. Recommendation: the owner tries `Ctrl+G` with Notepad already open once step 23 wires it. If it ends at once, an editor that ends in under a second with the file unchanged keeps the folder and the notice says where it is and to set `EDITOR`. Related, from the same review: on Windows a folder whose file an editor still holds open (Notepad, a VS Code process) cannot be removed, and is left in the user's temporary folder; it stays private to the user. | The owner, by hand, after step 23 | Before the first release |
