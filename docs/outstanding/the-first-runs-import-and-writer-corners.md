| **Found by the review of step 25, at lower confidence, by reading.** (1) **A name that runs a program can hide it.** After `--token-generator`, `--key-provider` or `--auth-process`, a rooted path is masked and imported (`crates/cineris-config/src/import.rs`), since none of those names ends in a word of `SHOWN_ENDINGS`; the maintainers settled that a rooted path under a credential's name is taken for a token. The endings that name a program could add `generator`, `provider`, `process`, `tool`, `bin`, `runner` and `launcher`, so that the program such a server runs is shown. (2) **Names to check before a reference is resolved** (step 30): an environment variable's or a header's name taken from another tool's file (`LD_PRELOAD`, `A=B`, one that begins with a digit) should be refused before any reference is resolved. (3) **An edited command keeps its old description:** at the commands step, `npm run test` edited to `npm run test:e2e` still says `runs jest`, and its entry says it was found in the file. (4) **`CINERIS_CONFIG`'s edges:** a relative value, or a literal `~/…`, is dropped without a word and the default `config.toml` is written; a missing path ending in `/` makes the first run due, but every write fails, so it runs at every start; a dangling link at `config.toml` counts as there (by design), while the loader treats it as no file and runs on the defaults without a word. (5) **The writer's leftovers:** `write.rs` (line 205 at the review's commit, `77ffbbcc`) ignores a removal that failed, so on Windows a scanner holding the file open can leave `.config.toml.<pid>-0.new`, owner-only, behind; and the fallback for a file system with no hard links runs on any error of the link but "exists". **Recommendations:** (1) and (2) with step 30's reading of `[mcp]`; (3) drop the description, or say it is of the command as found, once the command is edited; (4) refuse a relative or `~` value, and a path that ends in a separator, with a line that says so, and say when the file at the path is a link that leads nowhere; (5) report a removal that failed, and fall back only on the errors that mean the file system has no hard links. | Step 30 (the MCP client) for (1) and (2); step 32 (hardening) for the rest | Before the first release |
