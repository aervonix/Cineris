| **Running the system tests after tiers 1 and 2, and three at a time.** The blocking test job runs every tier in one nextest run, the system tests two at a time beside the rest, so tier 2 is measured partly under the system tests' load: on one Windows runner, `main`'s tier 2 took 27.4 s in a full run and 21.2 s alone. An experiment of the fifth tooling step (`try` run 43665893748, five rounds of each layout on one runner of each OS) ran `not sys_` first and then `sys_` alone: with the process group at 3, Windows tier 2 went from 22.5 s to 17.8 s (−21%) and tier 1 from 10.3 s to 8.6 s, the system tier was unchanged (54.5 s against 53.9 s), and the test step took 1.7 s more of wall time; at 4 the system tests slowed each other (+12.5 s); on Linux tier 2 went from 10.3 s to 9.9 s for 1.7 s more. No test failed in any of the 30 runs. It is the one change found that takes Windows tier 2 a quarter down on a slow runner (38 s to about 30 s); without it, item 1 of the step's target is not met.
