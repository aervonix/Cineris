| **The shell's environment rules stop at the shell.** Found by the shell environment's fixes ([../steps/shell-env-fixes/answered.md](../steps/shell-env-fixes/answered.md)), in a look at every place the product starts a process. `cineris_base::git`'s `start` (`crates/cineris-base/src/git.rs`, around line 188) adds `GIT_ENV` to the inherited environment and removes nothing, so every key variable the shell withholds reaches the git the harness runs to see what a command changed and to take a session's base, and every program git starts in turn. Of those, a filter driver a repository's configuration names is the one that matters: git runs it on `git status`, nothing turns every filter off, and a model can write the configuration (a protected path, asked about at every level below `unrestricted`, and found by the look around a confined command). Git is asked only in a trusted project, and while commands are confined the harness's git runs in the sandbox, read-only and with no network ([../architecture/06-permissions-and-sandbox.md](../architecture/06-permissions-and-sandbox.md), "As built in step 26"), so the key cannot leave by the network there; but what a filter prints becomes content the harness keeps (a base, a change list) and may show the model. At `unrestricted`, or with no sandbox enforcing, the filter runs with the user's rights and the keys. The same `start` passes `PATH` unfiltered, and the directory git runs in is the workspace, so a filter run through `sh -c` by a bare name finds a workspace file first when the harness's `PATH` has an empty or relative entry. **Recommendation:** give git's start the same treatment as the shell's (the removal list, a `PATH` of absolute directories), which needs the key list to reach `cineris-base` from the core; or say in [../security.md](../security.md) that a trusted repository's filters are given the user's environment, as the user's own git would give them. **Not changed in the fixes:** what git inherits is outside them. | The coordinator | Before the first release |
